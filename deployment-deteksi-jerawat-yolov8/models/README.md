# Lokasi model

File bobot harus bernama `best.pt` dan berada tepat pada folder ini:

`deployment-deteksi-jerawat-yolov8/models/best.pt`

Model yang tersedia saat paket dibuat sudah disertakan. Jika Anda mempunyai
`best.pt` terbaru dari hasil pelatihan terbaik di Google Colab, timpa file lama
dengan file terbaru dan pertahankan nama `best.pt`.
